# Task 13 — OpenShift Template

## There is no generator

Verified on oc 4.22.7: no `oc create template`, and `oc export --as-template` was removed in
OCP 4 (`error: unknown command "export"`). You write the wrapper — but not the contents:

```bash
oc explain template.parameters                 # name, value, required, description, generate, from
oc get template -n openshift --no-headers | head
oc get template nginx-example -n openshift -o yaml | head -40   # a real worked example

oc create deployment APPNAME \
  --image=quay.io/redhattraining/hello-world-nginx:latest \
  --dry-run=client -o yaml                     # the payload object
```

Paste that last output under `objects:`, indent one level, swap literals for `${PARAM}`.

## The template (`solutions/yaml/13-template.yaml`)

```yaml
apiVersion: template.openshift.io/v1
kind: Template
metadata:
  name: t13-template
parameters:
- name: APP_NAME
  required: true
- name: REPLICAS
  value: "1"
objects:
- apiVersion: apps/v1
  kind: Deployment
  metadata:
    labels:
      app: ${APP_NAME}
    name: ${APP_NAME}
  spec:
    replicas: ${{REPLICAS}}
    selector:
      matchLabels:
        app: ${APP_NAME}
    template:
      metadata:
        labels:
          app: ${APP_NAME}
      spec:
        containers:
        - image: quay.io/redhattraining/hello-world-nginx:latest
          name: hello-world-nginx
```

## `${{ }}` vs `${ }` — the whole point of this task

`${PARAM}` always substitutes as a **string**. `replicas` is an int32. `${{PARAM}}` substitutes
the raw value untyped. Verified locally:

```
${{REPLICAS}}  →  replicas: 2      # integer
${REPLICAS}    →  replicas: "2"    # string
```

Also note `value: "1"` stays quoted in `parameters:` — parameter values are always strings
there.

## Apply

```bash
oc new-project ex280-t13
oc create -f solutions/yaml/13-template.yaml
oc process t13-template -p APP_NAME=fromtemplate -p REPLICAS=2 | oc apply -f -
```

`oc create -f`, not `oc apply -f`, for the Template object itself — avoids the
last-applied-configuration warning.

## Check your work without touching the cluster

```bash
oc process --local -f solutions/yaml/13-template.yaml \
  -p APP_NAME=fromtemplate -p REPLICAS=2 -o yaml | grep -E 'name:|replicas:|image:'

oc process --local -f solutions/yaml/13-template.yaml -p REPLICAS=2
# The Template "t13-template" is invalid: parameter APP_NAME is required and must be specified
```

`--local` never contacts the API server. Good habit before committing anything to a cluster.

## Other parameter features

```yaml
- name: ADMIN_PASSWORD
  generate: expression
  from: '[a-zA-Z0-9]{16}'      # the only supported generator
- name: MEMORY_LIMIT
  displayName: Memory Limit
  description: Max memory the app may use
  value: 512Mi
```
