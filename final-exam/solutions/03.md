# Task 03 — Developer self-service

## oc path

```bash
oc adm policy remove-cluster-role-from-group self-provisioner system:authenticated:oauth
oc adm policy add-cluster-role-to-user       self-provisioner alice
```

## The part that makes this a real exam question

`oc` prints this warning:

```
Warning: Your changes may get lost whenever a master is restarted, unless you prevent
reconciliation of this rolebinding using the following command:
  oc annotate clusterrolebinding.rbac self-provisioners \
    'rbac.authorization.kubernetes.io/autoupdate=false' --overwrite
```

The cluster reconciles built-in RBAC back to defaults on apiserver restart. Without that
annotation your change **silently reverts** — and the exam scores end state after a reboot, so
this is not cosmetic.

Caveat from this run: if `remove-cluster-role-from-group` removed the binding's only subject,
the `self-provisioners` ClusterRoleBinding may be deleted entirely, and the annotate command
then returns `NotFound`. That is fine — there is no object left to reconcile back. Check with
`oc get clusterrolebinding self-provisioners` and only annotate if it exists.

## YAML path

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: self-provisioners
  annotations:
    rbac.authorization.kubernetes.io/autoupdate: "false"
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: self-provisioner
subjects:
- apiGroup: rbac.authorization.k8s.io
  kind: User
  name: alice
```

## Verify

```bash
oc get clusterrolebinding self-provisioners -o yaml
oc auth can-i create projectrequests --as=bob     # no
oc auth can-i create projectrequests --as=alice   # yes
```
