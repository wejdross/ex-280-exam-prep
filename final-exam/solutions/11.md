# Task 11 — Kustomize

## Layout

```
work/task11/base/kustomization.yaml
work/task11/base/deployment.yaml
work/task11/base/service.yaml
work/task11/overlays/exam/kustomization.yaml
```

Kustomize *is* a directory layout, so "the YAML way" is the only way here. The resources
inside it still come from generators:

```bash
oc create deployment kustom-app --image=quay.io/redhattraining/hello-world-nginx:latest \
  --replicas=1 --port=8080 --dry-run=client -o yaml > work/task11/base/deployment.yaml
oc create service clusterip kustom-app --tcp=8080:8080 \
  --dry-run=client -o yaml > work/task11/base/service.yaml
```

## base/kustomization.yaml

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
- deployment.yaml
- service.yaml
```

## overlays/exam/kustomization.yaml

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
- ../../base
namePrefix: exam-
labels:
- pairs:
    env: exam
  includeSelectors: false
replicas:
- name: kustom-app        # the name BEFORE namePrefix is applied
  count: 3
```

## Two things that trip people

**`commonLabels` is deprecated.** Current Kustomize (v5.7.1, bundled with oc 4.22) wants
`labels:` with `pairs:`. `includeSelectors: false` matters — set it to `true` and the label
gets added to `spec.selector.matchLabels` too, which is an immutable field on an existing
Deployment and the apply fails.

**`replicas[].name` uses the original name**, not the prefixed one. `kustom-app`, not
`exam-kustom-app`. The transformers are applied in a fixed order and `namePrefix` runs after
the replica patch.

## Apply

```bash
oc apply -k work/task11/overlays/exam -n ex280-t11
```

`-k` takes a **directory**, not a file. `kubectl kustomize <dir>` (or `oc kustomize`) renders
to stdout without applying — use it to check your work:

```bash
oc kustomize work/task11/overlays/exam | head -40
```

## Verify

```bash
oc get deployment exam-kustom-app -n ex280-t11 -o jsonpath='{.spec.replicas}{"\n"}'   # 3
oc get deployment exam-kustom-app -n ex280-t11 -o jsonpath='{.metadata.labels.env}{"\n"}'  # exam
oc get svc exam-kustom-app -n ex280-t11
grep 'replicas:' work/task11/base/deployment.yaml     # must still say 1 — base untouched
```

The last check is the point of an overlay: the base is never edited.

## Other transformers worth knowing

```yaml
nameSuffix: -v2
namespace: ex280-t11
commonAnnotations: {owner: platform}
images:
- name: quay.io/redhattraining/hello-world-nginx
  newTag: v1.0
configMapGenerator:
- name: app-config
  literals: [APP_MODE=production]
patches:
- path: patch.yaml
  target: {kind: Deployment, name: kustom-app}
```
