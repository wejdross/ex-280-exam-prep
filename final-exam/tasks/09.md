# Task 09 — Quota and limits (15 points)

In project `ex280-t09` (create it if it doesn't exist):

- Set a ResourceQuota named `t09-quota` limiting the project to a maximum of `4` pods, `2` CPU
  cores, and `2Gi` memory in total.
- Set a LimitRange named `t09-limits` so that any container which doesn't specify its own
  resources gets a default request of `100m` CPU / `128Mi` memory and a default limit of
  `200m` CPU / `256Mi` memory.
- Deploy a Deployment named `nolimits-app` (image `quay.io/redhattraining/hello-world-nginx:latest`,
  1 replica) WITHOUT specifying any resources in its container spec, and confirm it still
  schedules successfully because of the LimitRange defaults.

Your solution will be verified by inspecting the quota, limit range, and confirming the
Deployment's pod is Running with the expected effective resources.
