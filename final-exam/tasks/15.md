# Task 15 — Jobs and CronJobs (15 points)

In project `ex280-t15` (create it if it doesn't exist):

- Create a CronJob named `t15-cron` that runs every 5 minutes (`*/5 * * * *`), image
  `registry.access.redhat.com/ubi9/ubi-minimal:latest`, running `echo hello-ex280`.
- Without waiting for the schedule, trigger it manually once, producing a Job named
  `t15-manual` created from that CronJob (it must end up owned by `t15-cron`), which completes
  successfully.
- Once `t15-manual` has completed, **suspend the CronJob** so its schedule stops firing.
  (A `*/5` CronJob keeps creating Jobs, and `successfulJobsHistoryLimit` defaults to 3 — after
  three scheduled runs the controller garbage-collects your manually triggered Job, because
  `--from=cronjob/...` makes it owned by the CronJob. Suspending stops that.)
- Separately, create a one-off Job named `t15-oneshot` (same image) that runs `echo standalone`
  to completion.

Your solution will be verified by checking the CronJob's schedule, that it is suspended, that
`t15-manual` exists, is owned by `t15-cron`, completed successfully and logged `hello-ex280`,
and that `t15-oneshot` completed successfully and logged `standalone`.
