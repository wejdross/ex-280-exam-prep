# Task 12 — Helm deployment (15 points)

In project `ex280-t12` (create it if it doesn't exist):

- Add the Bitnami Helm chart repository (`https://charts.bitnami.com/bitnami`).
- Install the `nginx` chart from that repository as a release named `t12-nginx`, with the
  Service type set to `ClusterIP` (override the chart's default if different).
- The release must be in a `deployed` state and the resulting workload must reach `Running`.

Your solution will be verified by checking `helm list` status and the resulting pod/service.
