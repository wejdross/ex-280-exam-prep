# Task 13 — OpenShift Template (15 points)

- Author an OpenShift Template named `t13-template` in project `ex280-t13` (create the project
  if it doesn't exist) that:
  - Takes a required parameter `APP_NAME` (no default).
  - Takes a parameter `REPLICAS` defaulting to `1`.
  - Creates a Deployment (image `quay.io/redhattraining/hello-world-nginx:latest`) named after
    `APP_NAME`, with `REPLICAS` replicas.
- Process and apply the template with `APP_NAME=fromtemplate` and `REPLICAS=2`.

Your solution will be verified by checking the Template's parameters and the resulting
Deployment's name and replica count.
