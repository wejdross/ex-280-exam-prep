# Task 21 — ConfigMaps and Secrets (15 points)

In project `ex280-t21` (create it if it doesn't exist):

- Create a ConfigMap named `t21-config` with two keys:
  - `APP_MODE` = `production`
  - `APP_TIER` = `gold`
- Create a ConfigMap named `t21-files` from the file `assets/task21/app.properties`
  (already provided — do not author it yourself). The key inside the ConfigMap must be
  `app.properties`.
- Create a generic Secret named `t21-secret` with one key:
  - `API_KEY` = `s3cr3t-ex280`
- Deploy `config-app` (image `quay.io/redhattraining/hello-world-nginx:latest`, 1 replica) so
  that its container:
  - receives both keys of `t21-config` as environment variables **sourced from the ConfigMap**
    (not retyped as literal values),
  - receives `API_KEY` from `t21-secret` as an environment variable of the same name,
  - has `t21-files` mounted as a volume at `/etc/appconfig`, so that
    `/etc/appconfig/app.properties` exists inside the container.

Your solution will be verified by reading the environment variables and the mounted file from
**inside the running pod**, not just from the Deployment spec.
