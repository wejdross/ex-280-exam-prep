# Task 02 — Permissions (15 points)

A project named `ex280-t02` exists (create it if it doesn't). Configure permissions so that:

- User `alice` can create, modify, and delete most resources inside `ex280-t02`, but cannot
  manage roles/permissions or quota for the project.
- User `bob` can only view resources inside `ex280-t02` — no write access of any kind.
- Neither user should have any special access outside of `ex280-t02`.

Your solution will be verified by checking each user's effective permissions inside and outside
the project.
