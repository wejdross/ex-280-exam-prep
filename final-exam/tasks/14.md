# Task 14 — Operator installation (15 points)

Install an Operator via OLM with exactly these properties:

- Package name: `rh-service-binding-operator`
- Catalog source: `redhat-operators` (namespace `openshift-marketplace`)
- Channel: `stable`
- Install mode: cluster-wide (AllNamespaces), into namespace `openshift-operators`
- Approval: `Automatic`

The resulting ClusterServiceVersion (`service-binding-operator.vX.Y.Z`) must reach the
`Succeeded` phase.

Your solution will be verified by checking for a `service-binding-operator.*` CSV in
`Succeeded` phase in `openshift-operators`. Grading waits up to 4 minutes for an install that
is still in progress.
