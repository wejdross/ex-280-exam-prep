# Task 10 — Persistent storage (15 points)

In project `ex280-t10` (create it if it doesn't exist):

- Create a PersistentVolumeClaim named `t10-data` requesting `1Gi`, access mode `ReadWriteOnce`,
  using the cluster's default StorageClass.
- Deploy a Deployment named `storage-app` (image
  `registry.access.redhat.com/ubi9/ubi-minimal:latest`, command `["sleep", "3600"]`, 1 replica)
  that mounts this PVC at `/data`.
- Prove the storage survives a pod restart: data written to `/data` before the pod is deleted
  must still be present in the new pod.

Your solution will be verified by checking the PVC is Bound, the mount is correctly configured,
and by writing/reading a file across a pod restart.
