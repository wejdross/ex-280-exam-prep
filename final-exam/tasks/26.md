# Task 26 — Developer self-service: project template and cluster quota (15 points)

Two cluster-scoped configurations.

**A — Project request template**

- Create a project request template named `project-request` in namespace `openshift-config`,
  based on the cluster's built-in default, which additionally creates in every new project a
  LimitRange named `default-limits` giving containers a default request of `100m` CPU /
  `128Mi` memory and a default limit of `500m` CPU / `512Mi` memory.
- Configure the cluster so that this template is used for every new project request.

**B — Cluster resource quota**

- Create a ClusterResourceQuota named `ex280-crq` that applies to every project whose
  **requester** is `alice` (annotation `openshift.io/requester`), limiting those projects in
  aggregate to a maximum of `10` pods and `4Gi` of memory.

Your solution will be verified by checking that `project.config.openshift.io/cluster` points at
the template, that the template exists in `openshift-config` and contains the LimitRange, that
a newly created project actually receives a `default-limits` LimitRange, and by inspecting the
ClusterResourceQuota's selector and hard limits.

Note: `exam:reset` reverts the projectRequestTemplate setting; the template object itself and
the ClusterResourceQuota are deleted too.
