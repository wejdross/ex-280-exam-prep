# Task 07 — Non-HTTP service exposure (15 points)

In project `ex280-t07` (create it if it doesn't exist):

- Create a Pod named `raw-tcp`, labelled `app=raw-tcp`, image
  `registry.access.redhat.com/ubi9/python-311:latest`, whose container runs exactly this command
  (a raw-TCP echo server on port `9000`; `ubi-minimal` ships no `nc`, so this is the listener to
  use — copy it verbatim):

  ```yaml
  command: ["python3","-c","import socketserver;socketserver.TCPServer.allow_reuse_address=True;socketserver.TCPServer(('0.0.0.0',9000),type('H',(socketserver.StreamRequestHandler,),{'handle':lambda s: s.wfile.write(s.rfile.readline())})).serve_forever()"]
  ```

- Expose it to clients outside the cluster's pod network with a Service named `raw-tcp`:
  type `NodePort`, port `9000`, targetPort `9000`, nodePort `30900`. A Route is not the
  mechanism here.

Your solution will be verified by checking the Service's type/ports and by opening a raw TCP
connection to the node's IP on port `30900` from inside the cluster, sending a line and
expecting the same line echoed back. (Grading connects from inside the cluster on purpose: on
macOS `crc` does not forward node ports to the host, so a host-side test would fail even when
your configuration is correct.)
