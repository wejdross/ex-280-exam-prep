# Task 04 — Application deployment with health checks (15 points)

In project `ex280-t04` (create it if it doesn't exist), deploy an application:

- Name: `webapp`
- Image: `quay.io/redhattraining/hello-world-nginx:latest`
- Exactly 2 replicas.
- Container must request `100m` CPU / `128Mi` memory, and be limited to `250m` CPU / `256Mi` memory.
- A readiness probe must check HTTP GET `/` on port `8080` and a liveness probe must check TCP
  port `8080`.
- Expose it internally on port `8080` via a Service named `webapp`.

Your solution will be verified by inspecting the Deployment spec and confirming both replicas
reach `Ready`.
