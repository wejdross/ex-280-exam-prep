# Task 11 — Kustomize deployment (15 points)

Under `final-exam/work/task11/`, author a Kustomize base + overlay using exactly this layout:

```
work/task11/base/kustomization.yaml
work/task11/base/deployment.yaml
work/task11/base/service.yaml
work/task11/overlays/exam/kustomization.yaml
```

- `base/deployment.yaml`: Deployment `kustom-app`, image
  `quay.io/redhattraining/hello-world-nginx:latest`, 1 replica, containerPort `8080`.
- `base/service.yaml`: Service `kustom-app`, port `8080`, targetPort `8080`.
- The overlay at `overlays/exam/` must, WITHOUT modifying anything in `base/`:
  - Set replicas to `3`.
  - Add the label `env=exam` to all resources.
  - Prefix all resource names with `exam-`.
- Apply the `overlays/exam` overlay into project `ex280-t11` (create it if it doesn't exist).

Your solution will be verified by inspecting the resulting `exam-kustom-app` Deployment and
Service (names, `env=exam` label, replica count) and by confirming `base/deployment.yaml` still
declares 1 replica.
