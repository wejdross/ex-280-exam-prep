# Task 08 — Network policy (15 points)

In project `ex280-t08` (create it if it doesn't exist):

- Deploy three Deployments — `frontend`, `backend` and `other` — all in this same project, all
  using image `quay.io/redhattraining/hello-world-nginx:latest`, 1 replica each, each with a
  Service of the same name on port `8080` (targetPort `8080`).
- Each Deployment's pods must carry the label `app=<name>` (i.e. `app=frontend`, `app=backend`,
  `app=other` — this is what `oc create deployment` sets by default, and what grading selects on).
- Configure network policy so that:
  - `frontend` can reach `backend` on port `8080`.
  - `other` CANNOT reach `backend` on port `8080`.
  - Nothing else about default connectivity in the project should be affected beyond what's
    needed for this rule.

Your solution will be verified by running `curl` from inside the `frontend` pod and from inside
the `other` pod against `http://backend:8080`.
