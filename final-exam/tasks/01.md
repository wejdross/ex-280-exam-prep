and `carol`, all with password `redhatB1`). **Do not run `htpasswd`** — use the provided file.

- Users `alice` and `bob` must exist with password `redhatB1`.
- The identity provider must be named `htpasswd_ex280`.

Your solution will be verified by logging in as `alice` and `bob` with the given password and
confirming the identity provider configuration.
