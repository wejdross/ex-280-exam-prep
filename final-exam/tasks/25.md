# Task 25 — Image triggers (15 points)

In project `ex280-t25` (create it if it doesn't exist):

- Import `quay.io/redhattraining/hello-world-nginx:latest` into an ImageStream named
  `t25-app`, tag `latest`.
- Deploy `trigger-app` (1 replica) using that image.
- Configure the Deployment so that OpenShift **automatically updates its image whenever the
  `t25-app:latest` ImageStreamTag changes** — i.e. an OpenShift image trigger pointing at
  `t25-app:latest`, not a hardcoded registry string that you would have to edit by hand.
- The pod must be Running.

Your solution will be verified by checking the Deployment carries an
`image.openshift.io/triggers` annotation referencing `t25-app:latest` with `pause: false`, that
the trigger names the correct container, and that the trigger has actually fired — the
container's image must have been rewritten from a mutable `:latest` tag to a
`@sha256:...` digest matching the ImageStreamTag's current digest.
