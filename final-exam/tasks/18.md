# Task 18 — Image digests (15 points)

In project `ex280-t18` (create it if it doesn't exist):

- Import `quay.io/redhattraining/hello-world-nginx:latest` into an ImageStream named
  `t18-image` (tag `latest`).
- Determine the exact digest (`sha256:...`) that tag currently resolves to, and write it (just
  the `sha256:...` value, nothing else) into `final-exam/work/task18/digest.txt`.
- Deploy `digest-app` (1 replica) referencing the image by that exact digest (not by tag) — use
  the internal registry path for the ImageStream, pinned to the digest.

Your solution will be verified by comparing the recorded digest against the ImageStreamTag's
actual digest, and checking the Deployment's image reference.
