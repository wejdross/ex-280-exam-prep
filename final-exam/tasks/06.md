# Task 06 — Edge-terminated route (15 points)

In project `ex280-t06` (create it if it doesn't exist):

- Deploy `edge-app`: image `quay.io/redhattraining/hello-world-nginx:latest`, 1 replica
  (this image serves HTTP on port `8080`).
- Expose it with a Service named `edge-app` on port `8080` (targetPort `8080`).
- Use the certificate and key already provided at `assets/edge-app/tls.crt` and
  `assets/edge-app/tls.key` (RSA 2048, subject `CN=edge-app.apps-crc.testing`, valid until
  2036). **Do not run `openssl`** — the real exam hands you the cert files, and nothing here
  tests whether you remember its flags.
- Create a Route named `edge-app` with:
  - `edge` TLS termination, using that certificate and key (not the router's default wildcard cert),
  - hostname exactly `edge-app.apps-crc.testing`,
  - `insecureEdgeTerminationPolicy: Redirect` — plain HTTP must answer with a 3xx redirect to the
    HTTPS URL.

Your solution will be verified by checking the route's termination type, `insecureEdgeTerminationPolicy`,
that the certificate served on `:443` for that hostname has subject `CN=edge-app.apps-crc.testing`
(a wildcard `*.apps-crc.testing` cert means you used the router's default and fails), an HTTPS
request returning 2xx/3xx, and a plain HTTP request returning 3xx.

Note: `crc` on macOS has no wildcard DNS for `*.apps-crc.testing`. Grading resolves the hostname
itself; if you want to test the route by hand, add `127.0.0.1 edge-app.apps-crc.testing` to
`/etc/hosts` or use `curl --resolve edge-app.apps-crc.testing:443:127.0.0.1 ...`.
