# Task 22 — Scaling and autoscaling (15 points)

In project `ex280-t22` (create it if it doesn't exist):

- Deploy `scale-app` (image `quay.io/redhattraining/hello-world-nginx:latest`) starting with
  1 replica. Its container must request `50m` CPU and `64Mi` memory.
- Scale it manually to `3` replicas and confirm all 3 become Ready.
- Configure a HorizontalPodAutoscaler named `scale-app` targeting that Deployment, with:
  - minimum `3` replicas,
  - maximum `6` replicas,
  - a target of `70`% average CPU utilisation.

Your solution will be verified by checking the Deployment's CPU request (an HPA cannot compute
utilisation without one), that the Deployment reports 3 ready replicas, and the HPA's
scaleTargetRef, min, max and CPU target.

Note: the HPA's `TARGETS` column may read `<unknown>` for a few minutes after creation while
metrics-server collects its first samples. Grading does not depend on a live metric value.
