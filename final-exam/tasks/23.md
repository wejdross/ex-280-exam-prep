# Task 23 — Users, groups and group permissions (15 points)

This task builds on the HTPasswd identity provider from Task 01. The file
`assets/htpasswd_ex280` already contains all three users (`alice`, `bob`, `carol`, password
`redhatB1`) — use it, do not run `htpasswd` yourself.

- Add a third user `carol` to the existing `htpasswd_ex280` identity provider, so that
  `oc login -u carol -p redhatB1` succeeds. Do not break `alice` or `bob`.
- Create a group named `ex280-ops` whose members are exactly `alice` and `carol`.
- In project `ex280-t23` (create it if it doesn't exist), grant **the group** `ex280-ops`
  (not the individual users) the `view` role.
- `bob` must NOT be able to view resources in `ex280-t23`.

Your solution will be verified by logging in as `carol`, checking the group's membership,
checking that the RoleBinding in `ex280-t23` targets the group rather than users, and by
testing `alice`'s and `bob`'s effective read access in that project.
